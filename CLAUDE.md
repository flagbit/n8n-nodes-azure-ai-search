# n8n-nodes-azure-ai-search

n8n community node package that adds Azure AI Search as a vector store to n8n workflows. Provides Insert and Retrieve (similarity search) operations backed by `@azure/search-documents` and LangChain integration.

## Tech Stack

- **Runtime**: Node.js ≥18.10, pnpm ≥9.1 (enforced via `preinstall`)
- **Language**: TypeScript 5 → compiled to CommonJS (`dist/`)
- **Frameworks/libs**: LangChain (`@langchain/community`, `@langchain/core`), `@azure/search-documents` ^12.1
- **Build**: `tsc` + `gulp` (icon copy)
- **Peer dep**: `n8n-workflow` 1.48.0

## Repository Structure

```
credentials/          AzureAISearchApi credentials definition
nodes/
  vector_store/
    shared/           Reusable node factories (createVectorStoreNode, processDocuments)
    VectorStoreAzureAISearch/  Main node implementation
utils/                Shared helpers (logWrapper, N8nBinaryLoader, N8nJsonLoader, sharedFields)
dist/                 Compiled output (gitignored, generated by build)
```

## Local Development

**Prerequisites**: Node.js ≥18.10, pnpm 9.1.4

```bash
pnpm install
pnpm build        # tsc + gulp build:icons → dist/
pnpm dev          # tsc --watch
```

No `.env` file required for local build. To test in a live n8n instance, install the package locally in that n8n installation and configure credentials (Endpoint URL + API Key) via the n8n UI.

## Build / Test / Lint

```bash
pnpm build        # Compile TS and copy icons to dist/
pnpm lint         # ESLint over nodes/ credentials/ package.json
pnpm lintfix      # ESLint --fix
pnpm format       # Prettier over nodes/ credentials/
```

No automated test suite is present in this repository.

`prepublishOnly` runs `pnpm build && pnpm lint` using the stricter `.eslintrc.prepublish.js` config.

## Conventions

- **No default exports** (enforced by tslint rule `no-default-export`)
- **Strict TypeScript**: `noImplicitAny`, `strictNullChecks`, `noUnusedLocals` all enabled
- **Tabs for indentation** (tslint enforces tab width 2)
- **Single quotes** for string literals
- Commit style: Conventional Commits (`feat:`, `fix:`, `chore:`, etc.)
- Published artifact is `dist/` only (`"files": ["dist"]` in package.json)

## Gotchas / Notes

- pnpm is the **only** allowed package manager — `preinstall` script blocks npm/yarn via `only-allow pnpm`
- The `dist/` directory must be built before publishing or loading in n8n; it is not committed
- `n8n-workflow` is a peer dependency — it must be provided by the host n8n instance, not bundled
- Icon files (`.png`/`.svg`) are copied to `dist/` by gulp, not tsc — both steps are needed for a complete build
